WORDLY DICTIONARY
A simple dictionary web app. It used to search for word to see its meaning, pronunciationand synonnyms, and save your favourite words for 
later.
FEATURES
1. Look up definitons, pruonunciation and synonyms
2. Hear the word spoken aloud (Listen button)
3. Save and unsave words; saved words are kept in your browser (localStorage)
4. Friendly error messages for empty searches, unknown words and network problems
   
BUILT WITH
1. HTML, CSS and Javascript
2. TailwindCSS
3. Datamuse API for word data
4. Jest for testing
   
GETTING STARTED
Download or clone this project.
Open index.html in your browser.
Type a word and click Search.

RUNNING TESTS
npm install --save-dev jest jest-enviroment-jsdom
npm jest

PROJECT STRUCTURE
index.html       # Page layout
style.css        # Custom styles
index.js        # App logic
index.test.js  # Jest tests
